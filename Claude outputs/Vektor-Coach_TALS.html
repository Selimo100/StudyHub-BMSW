Grundlagen – Repetition

Das hast du schon gemacht. Hier nur das Wichtigste zum schnellen Auffrischen.

Vektor vs. Skalar

Ein Vektor hat Betrag (Länge) und Richtung. Alle Pfeile mit gleicher Länge und Richtung sind derselbe Vektor – jeder einzelne Pfeil heisst Repräsentant.

Ein Skalar hat nur einen Betrag.

Gleich sind zwei Vektoren nur, wenn Länge und Richtung übereinstimmen – wo der Pfeil liegt, spielt keine Rolle (freier Vektor). Bei einer Kraft, die an einem bestimmten Punkt angreift, zählt die Lage mit: das ist ein gebundener Vektor.

  • Skalar: Temperatur, Zeit, Masse, Druck, Dichte, Energie, Alter, Länge
  • Vektor: Geschwindigkeit, Kraft, Verschiebung, Wind, Beschleunigung, Strömung, Lichtstrahl
Falle (Nr. 2)Aus a = b folgt a = b (gleiche Länge). Aber aus a = b folgt nicht a = b – die Richtung kann verschieden sein.

Addition & Subtraktion

Addieren: Pfeile aneinanderhängen (Spitze an Fuss). Resultierende = vom Anfang des ersten zur Spitze des letzten Pfeils.

AB + BC = AC  («innere Buchstaben kürzen sich»)

Subtrahieren: Gegenvektor addieren: a − b = a + (−b). Und −AB = BA.

Geschlossene Vektorkette ⇒ Summe = Nullvektor 0.

Trick für TermeJede Subtraktion in eine Addition mit umgedrehten Buchstaben verwandeln, dann so ordnen, dass Ende = nächster Anfang:
XY − ZY + XZ = XY + YZ + XZ = XZ + XZ = 2XZ

Rechengesetze (gelten wie bei Zahlen)

a + b = b + a (Kommutativ) · a + (b + c) = (a + b) + c (Assoziativ) · a − a = 0 · |a − b| = |b − a|

Falle (Nr. 5 / 6)|a + b| = |a| + |b| gilt nur, wenn a und b die gleiche Richtung haben. Sonst ist die Summe kürzer (Dreiecksungleichung). Und: Betrag (Zahl) ≠ Vektor – «c = a + b» ist falsch geschrieben.

Multiplikation mit einer Zahl & Linearkombination

Neu für dich – aber einfach: Eine Zahl vor dem Vektor streckt, staucht oder dreht ihn um.

k · a

  • Betrag: |k·a| = |k| · |a|
  • k > 0: gleiche Richtung wie a
  • k < 0: Gegenrichtung
  • 1·a = a,  (−1)·a = −a,  0·a = 0

Rechengesetze: k(a + b) = ka + kb · (k + m)a = ka + ma · k(ma) = (km)a — du darfst also ausmultiplizieren und zusammenfassen wie in der Algebra.

Linearkombination

Eine Summe/Differenz von Vektoren, jeder mit einem Faktor: das Ergebnis ist wieder ein Vektor.

v = a + 2·b − c

So konstruierst du sie
  1. Jeden Summanden einzeln bilden: 2b (doppelt so lang), −c (umgedreht) …
  2. Alle Pfeile Spitze an Fuss aneinanderhängen – Reihenfolge egal.
  3. Resultierende vom Startpunkt zur letzten Spitze einzeichnen und beschriften.
Terme vereinfachenWie in der Algebra: ausmultiplizieren, gleiche Vektoren zusammenfassen.
z = 3(a + 2x) − 4(x2 + y) − 5b = 3a + 6x − 2x − 4y − 5b = 3a + 4x − 4y − 5b
Danach x, y durch a, b ersetzen (Skript Aufg. 4e → Resultat 3a − 13b).
Häufiger FehlerBeim Konstruieren vergessen, dass ein Minus die Richtung dreht: −3c zeigt in die Gegenrichtung von c und ist 3-mal so lang.

Zerlegung & Vektoren in Figuren

Das ist der anspruchsvollste Teil (Würfel, Pyramide, Dreieck). Mit einer festen Methode wird er zur Routine.

Die Weg-Methode

Gesucht ist z. B. HB durch a, b, c:

  1. Startpunkt (H) und Zielpunkt (B) in der Skizze markieren.
  2. Einen Weg nur entlang bekannter Kanten suchen.
  3. Jede Kante in Pfeilrichtung = +, gegen die Pfeilrichtung = −.
  4. Alles addieren und zusammenfassen.

Welcher Weg, ist egal – das Resultat ist immer gleich.

Beispiel Würfel (Nr. 16)

AM (M Mitte von FG): A → B → F → M = a + c + ½b

Die drei Punkte, die du auswendig kennen musst

Mittelpunkt einer Strecke

Halber Weg: AM = ½ AB.

Schwerpunkt S im Dreieck

Liegt auf der Seitenhalbierenden, ⅔ ab der Ecke. Kurzformel: AS = ⅓(AB + AC).

Diagonalenschnitt / Würfelmitte

Halbiert die Diagonale: AM = ½AC, im Würfel AK = ½(a + b + c).

Zerlegung in zwei Richtungen

Einen Vektor a in b und c zerlegen heisst: Zahlen x, y finden mit a = x·b + y·c.

Grafisch: Durch Anfangs- und Endpunkt von a je eine Parallele zu b und zu c zeichnen. Es entsteht ein Parallelogramm, dessen Seiten xb und yc sind. Dann abmessen: wie oft passt b hinein?

Rechnerisch (mit Koordinaten): komponentenweise ein Gleichungssystem mit 2 Unbekannten aufstellen → TR (siehe Tab TI-Nspire).

Keine LösungWenn b und c parallel (kollinear) sind, kann man a nicht zerlegen (ausser a ist auch parallel).

Kollineare Vektoren

Kollinear = parallel oder antiparallel = «linear abhängig». Es gibt eine Zahl k mit b = k·a.

Test: Beide Komponenten durcheinander teilen – kommt zweimal dieselbe Zahl heraus, sind sie kollinear.

2−3 und −69: −6 : 2 = −3 und 9 : (−3) = −3 ⇒ kollinear, k = −3.

Fehlende Koordinate (Nr. 49)p = 4−6 kollinear zu r = −5r₂. Aus der bekannten Komponente k bestimmen: −5 = k·4 ⇒ k = −1.25. Dann r₂ = −1.25·(−6) = 7.5.
Kollinear vs. linear unabhängigKollinear hängt nur von der Richtung ab, nie von der Länge – zwei gleich lange Vektoren müssen nicht kollinear sein. In der Ebene sind höchstens zwei Vektoren linear unabhängig: Jeder dritte lässt sich als Linearkombination der beiden anderen schreiben (genau das ist die Zerlegung).

Zerlegung / Koeffizienten bestimmen – Methode A: Gleichungssystem

Beispiel Skript Aufg. 7a: c = 77 soll x·a + y·b werden, mit a = 31, b = −12.

  1. Auf Papier komponentenweise aufschreiben:
    x-Zeile: 3x − 1y = 7
    y-Zeile: 1x + 2y = 7
  2. menu → Algebra → Lineares Gleichungssystem lösen
  3. Anzahl Gleichungen: 2, Variablen: x,y → OK
  4. Die zwei Gleichungen eintippen → enter
linSolve({3x-y=7, x+2y=7},{x,y}) ▸ {3,2} ⇒ x = 3, y = 2 ⇒ c = 3·a + 2·b

Methode B: in einer Zeile mit simult

augment(a,b) stellt die zwei Spaltenvektoren nebeneinander (= Koeffizientenmatrix). simult löst dann das System. Sehr schnell, wenn die Vektoren schon gespeichert sind.

a:=[3;1] b:=[-1;2] c:=[7;7] simult(augment(a,b),c) ▸ [3] [2]

Auch mit drei Unbekannten-Vektoren funktioniert das nur, wenn es genau 2 Koeffizienten gibt. Bei Aufgaben wie Nr. 50 (s = xa + yb − 1.5xc) erst zusammenfassen: x(a − 1.5c) + yb → simult(augment(a-1.5·c,b),s) ▸ [−4; −3.5].

Nach einem Vektor auflösen (Aufg. 7b)

½a + 3b = c → wie eine normale Gleichung umformen: b = (c − ½a) : 3. Dann eintippen:

(c-0.5·a)/3 ▸ [1 ] [-1.5]

Kollinear prüfen mit dem TR

Zwei Vektoren nebeneinander in eine Matrix: ist die Determinante 0, sind sie kollinear. (menu → Matrix & Vektor → Determinante)

det(augment([3;7],[4.5;10.5])) ▸ 0 → kollinear det(augment([3;7],[5;9])) ▸ -8 → nicht kollinear
